========================================================================
MINDFOCUS BOOKS - EXPLORE & 3D DOSSIER MODULE PACKAGE
========================================================================

FILES INCLUDED IN THIS ZIP:
1. explore.js          - Complete JavaScript logic for Explore, Instant Search, & 3D Dossier Sheet
2. explore.css         - Complete CSS styles for cards, grids, 3D perspective, animations, & modals
3. explore.html        - HTML component markup for the Explore section and Dossier Modal
4. standalone-demo.html - Full standalone test file you can double-click and open in ANY browser (mobile or PC)

HOW TO TEST STANDALONE DEMO:
- Simply double-click 'standalone-demo.html' in your browser.
- Tap any book card, spotlight, or surprise pick to test the 3D Dossier Sheet.
- Tap 'Open Full Book Page & Read' to see the reader trigger.
- Tap '+ Add to My Library' to test the instant addition badge.

INTEGRATION IN YOUR APP:
1. In your HTML <head> or stylesheet imports:
   <link rel="stylesheet" href="explore.css">

2. In your HTML body:
   Include the markup from 'explore.html'.

3. In your script tags at the bottom:
   <script src="explore.js"></script>
